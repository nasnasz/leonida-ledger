Leonida Ledger is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. It shows the official names, descriptions and grades verbatim, adds an original 60–140 word guide and one to three cited sources for every trophy, and turns the list into a six-stage roadmap with per-stage progress and eight story-window missables explained. Progress is saved in the browser, can be exported to and imported from JSON, filtered by kind or grade, searched, and read with a spoiler shield that keeps unearned story trophies hidden. Everything is static files under `app/`: no build step, no network calls, no external assets. Run the command below, then open http://localhost:8080.

## Run it

```sh
node serve.ts
```
